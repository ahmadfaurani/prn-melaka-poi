## 1. Purpose

Intelligence collection workstream targeting 20 Melaka-based political figures (POIs) across three coalitions: BN/UMNO+MCA+MIC (14), PN/Bersatu+PAS (3), PH/Amanah+DAP+PKR (3). ## 7. Content Filter

Only collect articles DIRECTLY related to:
1. Melaka state politics, governance, or election
2. Named POIs from the roster above (20 figures)
3. Melaka DUN constituencies (all 28 seats, N01–N28)
4. Melaka parliamentary constituencies (P134–P139)
5. Coalition dynamics SPECIFICALLY in Melaka context
6. Federal-state intersection topics (defence, PAC, federal ministries) where Melaka POIs are actors
7. EXCO portfolio activities (housing, infrastructure, education, religious affairs, digital, health)
8. Social media and digital campaign activity by Melaka POIs

## 8. Auto-Approve Loop

Each LLM-driven cronjob (CJ-MLK-01 through CJ-MLK-05, CJ-MLK-09, CJ-MLK-10) implements the Self-Improving Collection Loop:
- End of cycle: generate TOP 3 PIR suggestions → write to `07-AUDIT/top3-mlk-suggestions-CJMLK0X.md`
- Start of next cycle: read that file and incorporate as AUTO-APPROVED additional search queries
